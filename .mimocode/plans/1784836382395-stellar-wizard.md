# Plano: Serviço de Cadastro de Materiais via CIGAM Integrador

## Objetivo
Criar um novo serviço dedicado para cadastro, listagem e sincronização de materiais com o CIGAM Integrador (endpoint `.ashx`), separado da API REST existente que usa Bearer token.

## Arquitetura

```
┌─────────────────────────────────────────────────────────┐
│                  Chocmaster Backend                       │
│                                                          │
│  ┌──────────────────────┐   ┌─────────────────────────┐ │
│  │  API CIGAM (atual)   │   │  Integrador CIGAM (novo)│ │
│  │  Bearer token auth   │   │  PIN auth por ambiente  │ │
│  │  /API/api/...        │   │  .ashx endpoints        │ │
│  └──────────────────────┘   └─────────────────────────┘ │
│                                                          │
│  cigamHttpClient.ts      cigamIntegradorHttpClient.ts   │
│  cigamPedidoService      cigamMateriaisIntegradorService│
│  cigamClienteService     (cadastro, listar, sync)       │
└─────────────────────────────────────────────────────────┘
```

### 2. `cigamIntegradorHttpClient.ts`

Client HTTP dedicado para o Integrador. Diferente do `CigamHttpClient` existente:
- **Auth via PIN** no payload (não Bearer header)
- **Base URL** de variável de ambiente (não `url_ambiente` do banco)
- **Endpoints** no formato `.ashx/metodo`

```typescript
@injectable()
export class CigamIntegradorHttpClient {
  private readonly client: AxiosInstance;
  
  constructor() {
    this.client = axios.create({
      baseURL: process.env.CIGAM_INTEGRADOR_URL,
      timeout: 30000,
      headers: { 'Content-Type': 'application/json' },
    });
  }

  private getPin(ambiente: string): string {
    const key = ambiente === 'producao' 
      ? 'CIGAM_INTEGRADOR_PIN_PRODUCAO' 
      : 'CIGAM_INTEGRADOR_PIN_HOMOLOGACAO';
    const pin = process.env[key];
    if (!pin) throw new Error(`PIN do Integrador não configurado para ambiente: ${ambiente}`);
    return pin;
  }

  async post<T>(endpoint: string, payload: any, ambiente: string): Promise<T> {
    const response = await this.client.post<T>(endpoint, {
      pin: this.getPin(ambiente),
      ...payload,
    });
    return response.data;
  }

  async get<T>(endpoint: string, params?: any): Promise<T> {
    const response = await this.client.get<T>(endpoint, { params });
    return response.data;
  }
}
```

### 4. `cigamMateriaisIntegradorService.ts`

Serviço de negócio com cadastro, listagem e sincronização:

```typescript
@injectable()
export class CigamMateriaisIntegradorService {
  constructor(
    @inject(CigamIntegradorHttpClient) private readonly integradorClient: CigamIntegradorHttpClient,
    @inject(UsuarioCigamService) private readonly usuarioCigamService: UsuarioCigamService,
    @inject(ProdutoRepository) private readonly produtoRepository: ProdutoRepository,
    @inject(DeParaProdutosRepository) private readonly deParaProdutosRepository: DeParaProdutosRepository,
  ) {}

  private async getActiveEnv(): Promise<string> { ... }

  async cadastrarMaterial(input: CadastrarMaterialIntegradorInput): Promise<void> { ... }
  async listarMateriais(): Promise<CigamIntegradorMaterialListItem[]> { ... }
  async sincronizarComLocal(): Promise<SincronizacaoResult> { ... }
  async cadastrarEmapear(input: CadastrarEMapearInput): Promise<void> { ... }
}
```

**Métodos:**

| Método | Descrição |
|---|---|
| `cadastrarMaterial` | Envia material para o Integrador cadastrar |
| `listarMateriais` | Lista materiais existentes no Integrador |
| `sincronizarComLocal` | Compara materiais do Integrador com a tabela local e cria/atualiza De-Para |
| `cadastrarEmapear` | Cadastra no Integrador E cria o registro local + De-Para em uma operação |
